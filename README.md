# hartia-demo — демо-сайт пивоварни «Хартия» (Тюмень)

Статический сайт: чистые HTML + CSS + vanilla JS (3D-кега на Three.js). Без сборки и зависимостей.

- Сайт закрыт от поисковиков (`noindex` + `robots.txt`) — это демо, продажи не открыты.
- Форма брони кег (`arenda-keg.html`) отправляет заявки в API бота аренды (`POST /api/order`), после брони даёт deep-link в Telegram/MAX-бота для отслеживания статуса.
- Локальный просмотр: `python -m http.server 8000` → http://localhost:8000 (18+ гейт отключается параметром `?nogate`).
